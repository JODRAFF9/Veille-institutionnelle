# Financement

- Budget financé par les contributions des membres selon une formule fondée sur la taille de l'économie
- Partie I obligatoire pour tous, partie II pour les programmes à participation volontaire
- Contributions volontaires de pays, fondations et entreprises
- Programme de travail et budget adoptés tous les deux ans
- Les États-Unis sont le premier contributeur (à vérifier)
