# Gouvernance

- Conseil : un représentant permanent par pays membre, décisions par consensus
- Réunion du Conseil au niveau ministériel chaque année, en général en juin
- Secrétariat dirigé par un secrétaire général : Mathias Cormann depuis 2021 (à vérifier)
- Environ 300 comités et groupes de travail préparent les travaux
- Directions thématiques : économie, statistiques, éducation, fiscalité, environnement, gouvernance
