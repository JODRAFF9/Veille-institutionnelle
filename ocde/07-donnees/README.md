# Données

- OECD Data Explorer : requêteur principal, a remplacé OECD.Stat en 2024 (à vérifier)
- data.oecd.org : portail grand public avec indicateurs et visualisations
- API SDMX sur sdmx.oecd.org : dataflows, structures et séries
- PISA, PIAAC et statistiques de l'aide publique au développement du CAD
- Les données reprennent des déclarations nationales, avec contrôles et harmonisation par l'OCDE
