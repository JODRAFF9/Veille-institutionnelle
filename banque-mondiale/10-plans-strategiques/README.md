# Plans stratégiques

À vérifier sur worldbank.org avant de citer.

| Plan | Contenu |
|---|---|
| Objectifs jumeaux (2013) | Fin de l'extrême pauvreté, prospérité partagée |
| Feuille de route d'évolution (Evolution Roadmap, 2023) | Nouvelle vision et mission, élargissement aux biens publics mondiaux, plus de capacité de prêt |
| Plan d'action pour le climat 2021-2025 | Cible de cofinancement climat de 35 % des financements, 45 % visés ensuite |
| Stratégie FCV 2020-2025 | Fragilité, conflit, violence |
| Stratégie genre 2024-2030 | Égalité femmes-hommes |
| Augmentation de capital 2018 | Environ 13 milliards USD pour la BIRD, 5,5 pour la SFI |
| IDA21 (2024) | Reconstitution des ressources de l'IDA |
| Mission 300 | Électricité pour 300 millions d'Africains d'ici 2030, avec la BAD |
| Scorecard institutionnel | Indicateurs de résultat suivis par le conseil |

Où chercher : worldbank.org/en/about/leadership, Development Committee papers, documents du conseil.
