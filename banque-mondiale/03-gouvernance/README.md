# Gouvernance

- **Conseil des gouverneurs** : un gouverneur par pays membre (souvent le ministre des finances). Instance suprême, réunion annuelle.
- **Conseil d'administration** : 25 administrateurs résidents à Washington, approuvent les prêts et les politiques. Les plus gros actionnaires (États-Unis, Japon, Allemagne, France, Royaume-Uni, plus Chine, Inde, Russie, Arabie saoudite) ont chacun un siège.
- **Droits de vote** : fondés sur les parts de capital. Les États-Unis détiennent la plus grande part et un droit de blocage sur les décisions à majorité qualifiée de 85 %.
- **Président** : choisi par le conseil, traditionnellement un ressortissant des États-Unis. Mandat de cinq ans renouvelable.
- **Comité du développement** : comité ministériel conjoint avec le FMI, avis sur le développement.
- **Revue de l'actionnariat** : tous les cinq ans, rééquilibrage progressif vers les pays émergents (augmentation de capital de 2018).

Présidents : McCloy, Black, Woods, McNamara, Clausen, Preston, Conable, Wolfensohn, Wolfowitz, Zoellick, Kim, Malpass, Banga.
