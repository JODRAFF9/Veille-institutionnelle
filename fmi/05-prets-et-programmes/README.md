# Prêts et programmes

| Instrument | Usage |
|---|---|
| SBA (accord de confirmation) | Besoin de balance des paiements à court terme |
| EFF (facilité élargie de crédit) | Problèmes structurels, plus longue durée |
| RFI / RCF | Financement d'urgence rapide |
| FCL / PLL / SLL | Lignes de précaution pour pays aux fondamentaux solides |
| ECF / SCF / RCF (PRGT) | Prêts à taux zéro pour pays à faible revenu |
| RSF | Prêts pour la résilience climatique et pandémique |

**Conditionnalité** : actions préalables, critères de réalisation quantitatifs, repères structurels, objectifs indicatifs. Revues périodiques liées aux décaissements.

**Dette** : cadre commun du G20 (2020) pour les traitements de dette, Table ronde mondiale sur la dette souveraine (2023), analyse de viabilité de la dette (DSA).
