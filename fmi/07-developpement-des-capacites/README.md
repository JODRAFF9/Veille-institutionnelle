# Développement des capacités

Assistance technique et formation, souvent gratuites pour les pays pauvres.

- Domaines : finances publiques, politique monétaire, supervision bancaire, statistiques, lutte contre le blanchiment.
- **Centres régionaux** : AFRITAC (Afrique), CARTAC (Caraïbes), centres du Pacifique, du Moyen-Orient, etc.
- **Institut pour le développement des capacités (ICD)** : cours en ligne et en présentiel, accessible via imf.org/external/np/ins.
- Financement partagé avec des partenaires bilatéraux.
