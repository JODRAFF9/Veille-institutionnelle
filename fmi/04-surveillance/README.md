# Surveillance

Base juridique : article IV des statuts.

- **Consultations article IV** : en général annuelles avec chaque pays, mission sur place, rapport publié avec accord du pays.
- **Surveillance multilatérale** : WEO, GFSR, Fiscal Monitor, External Sector Report, Global Policy Agenda.
- **FSAP** (programme d'évaluation du secteur financier, depuis 1999) : stabilité financière, obligatoire pour les 29 pays systémiques environ.
- **ROSC** : rapports sur le respect des normes et codes.
- **Surveillance intégrée** : revue complète de la surveillance (Comprehensive Surveillance Review), tous les cinq ans environ.
- **Alertes précoces** : vulnérabilités, risques de dette.
