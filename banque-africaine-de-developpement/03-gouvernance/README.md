# Gouvernance

- Conseil des gouverneurs : un gouverneur par pays membre, assemblées annuelles
- Conseil d'administration de 20 administrateurs, dont 13 pour les pays régionaux (à vérifier)
- Pays régionaux : majorité du capital et des voix, environ 60 % (à vérifier)
- Président élu par les gouverneurs pour cinq ans : Akinwumi Adesina de 2015 à 2025, puis Sidi Ould Tah (à vérifier)
