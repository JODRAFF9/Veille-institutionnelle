# Glossaire

- **WDI** : World Development Indicators, base phare de la Banque mondiale (source 2).
- **WEO** : World Economic Outlook, publication du FMI avec prévisions.
- **IFS** : International Financial Statistics.
- **BOP** : Balance of Payments.
- **DOTS** : Direction of Trade Statistics.
- **SDMX** : Statistical Data and Metadata eXchange, standard d'échange statistique.
- **Dataflow** : jeu de données exposé par une API SDMX.
- **PPA** : parité de pouvoir d'achat.
- **PIP** : Poverty and Inequality Platform.
- **e-GDDS / SDDS** : normes de diffusion des données du FMI.
- **Millésime** : version datée d'une publication (par exemple WEO avril 2026).
